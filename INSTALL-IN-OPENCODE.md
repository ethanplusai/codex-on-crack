# OpenCode installation

The existing Astra Flash Orchestrator OpenCode integration is preserved in
[legacy/astra-flash-orchestrator](legacy/astra-flash-orchestrator/README.md).
The Codex plugins and embedded panel are separate from this integration.

From the repository root:

```sh
cd legacy/astra-flash-orchestrator
```

Then follow the original [OpenCode installation guide](legacy/astra-flash-orchestrator/INSTALL-IN-OPENCODE.md).
All commands in that guide run from this legacy package directory. Existing
installations do not need to migrate to the Codex plugin to keep working.
The original Codex installer is also retained in the same directory for users
who want to keep the original Astra + Flash arrangement.
